# Márcio Rogério | Corretor de Imóveis

Website institucional para **Márcio Rogério - Corretor de Imóveis (CRECI 59.138-F)**, especializado em curadoria imobiliária de alto padrão, lançamentos e consultoria para moradia e investimentos.

---

## 🚀 Tecnologias Utilizadas

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **TypeScript**

---

## 📦 Como Rodar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone <URL_DO_SEU_REPOSITORIO>
   cd "MARCIO ROGERIO CORRETOR - SITE"
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   Abra [http://localhost:8443](http://localhost:8443) (ou a porta indicada no terminal).

---

## 🛠️ Build para Produção

Para gerar a versão otimizada pronta para publicação:

```bash
npm run build
```

Os arquivos estáticos prontos para deploy serão gerados na pasta `dist/`.

---

## 🌐 Publicação (Deploy)

Este projeto pode ser publicado diretamente e de forma gratuita em:
- **Vercel:** Importe o repositório do GitHub; o framework Vite será detectado automaticamente.
- **Netlify:** Conecte o repositório, defina o comando de build como `npm run build` e o diretório de publicação como `dist`.
- **GitHub Pages:** Pode ser configurado via GitHub Actions.
